# IPI Support

IPI is an early-stage open-source project. Community support is public and
best-effort; there is currently no guaranteed response time or production
support agreement.

## Where to go

| Need | Channel |
| --- | --- |
| Usage or architecture question | [GitHub Discussions](https://github.com/orgs/ipicoin/discussions) |
| Reproducible software defect | Issue in the affected repository |
| Protocol or governance change | [IPI Improvement Proposal](ipi/README.md) |
| Security vulnerability | Private process in [SECURITY.md](SECURITY.md) |
| Conduct concern | Private process in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Before asking, search existing issues and Discussions and read the repository's
README. Include the repository revision, operating system, configuration with
secrets removed, expected result, actual result, and the smallest reproducible
example.

Please do not send support requests to individual contributors. Public,
searchable answers reduce repeated work and make the project easier to join.
